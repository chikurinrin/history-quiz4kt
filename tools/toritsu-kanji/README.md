# 都立高校入試 漢字マスター

読み・書き対応、漢検レベル別、自動採点履歴、音読み訓読み・意味の解説、
自動再生（フラッシュカード）、日別の学習履歴グラフを備えた漢字学習ツールです。
バックエンド不要・すべてブラウザ内（localStorage）で完結します。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面本体＋キャッシュ対策ローダー |
| `style.css` | デザイン |
| `script.js` | 動作ロジック |
| `data.js` | 問題データ（約850語） |
| `kanji-readings.js` | 漢字→音読み・訓読み辞書 |
| `word-meanings.js` | 語→意味の辞書 |

## GitHub Pages で公開する手順

1. このリポジトリを GitHub に push する。
2. GitHub の **Settings → Pages** を開く。
3. **Build and deployment** の Source を「**Deploy from a branch**」にする。
4. Branch を「**main**」／フォルダ「**/(root)**」に設定して **Save**。
5. 数分後、次の URL で公開されます（`ユーザー名`・`リポジトリ名`は自分のもの）:

   ```
   https://<ユーザー名>.github.io/<リポジトリ名>/tools/toritsu-kanji/
   ```

   この URL をスマートフォンのホーム画面に追加すると、アプリのように使えます。

※ファイルの参照はすべて相対パスなので、サブフォルダのままで動作します。

## ★ 改修後にスマホで「最新版」を確実に読み込ませる方法

ブラウザは一度読んだファイルを保存（キャッシュ）するため、更新しても
古い画面が表示されることがあります。これを防ぐ仕組みを `index.html` に入れています。

**機能を直したら、`index.html` の先頭にあるバージョン番号 `V` を書き換えてから
GitHub に push してください。** これだけで、スマホでも必ず新しい版が読み込まれます。

```html
<!-- index.html の <head> 内 -->
var V = '2026-07-03a';   // ← ここを書き換える（例: '2026-07-03b'）
```

- 目安: 日付＋末尾のアルファベットを1つ進める（`a`→`b`→`c`…）だけでOK。
- 「毎回自動で最新にしたい（番号を書き換えたくない）」場合は、次のように変更します:

  ```js
  var V = Date.now();
  ```

  ※この方式は毎回ファイルを取得し直すため、常に最新になりますが通信量は増えます。

## ローカルでの確認

`index.html` をブラウザで直接開くか、簡易サーバーで確認します。

```bash
python -m http.server 8080
# → http://localhost:8080/tools/toritsu-kanji/
```

## データの保存について

学習履歴・成績・追加問題・日別の学習量は、その端末のブラウザの
localStorage に保存されます（端末・ブラウザをまたいでの同期はされません）。
