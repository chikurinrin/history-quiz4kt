
# 都立高校入試 漢字マスター

読み・書き対応、漢検レベル別、自動採点履歴、音読み訓読み・意味の解説、
自動再生（フラッシュカード）、日別の学習履歴グラフを備えた漢字学習ツールです。
バックエンド不要・すべてブラウザ内（localStorage）で完結します。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面本体＋ローダー＋Service Worker登録 |
| `style.css` | デザイン |
| `script.js` | 動作ロジック |
| `data.js` | 問題データ（約850語） |
| `kanji-readings.js` | 漢字→音読み・訓読み辞書 |
| `word-meanings.js` | 語→意味の辞書 |
| `kanji-priority.js` | 出題優先度（頻出度の目安） |
| `sw.js` | Service Worker（オンライン時は常に最新を取得） |

## GitHub Pages で公開する手順

1. このリポジトリを GitHub に push する。
2. GitHub の **Settings → Pages** を開く。
3. **Build and deployment** の Source を「**Deploy from a branch**」にする。
4. Branch を「**main**」／フォルダ「**/(root)**」に設定して **Save**。
5. 数分後、次の URL で公開されます（`ユーザー名`・`リポジトリ名`は自分のもの）:

   ```
   https://<ユーザー名>.github.io/<リポジトリ名>/tools/toritsu-kanji/
   ```

   この URL をスマートフォンのホーム画面に追加すると、アプリのように使えます。

※ファイルの参照はすべて相対パスなので、サブフォルダのままで動作します。

## ★ 更新が反映される仕組み（Service Worker）

`sw.js`（Service Worker）を使い、**オンライン時は毎回サーバーから最新を取得**します。
一度この仕組みが入った端末では、以後 GitHub に上げた更新が**自動で反映**されます
（バージョン番号の手動更新は不要）。オフライン時は前回取得した内容で動作します。

### すでに古い画面がキャッシュされている端末の直し方（初回だけ）

この仕組み自体も一度は端末に読み込まれる必要があります。すでに古い版が
キャッシュされている場合は、次のいずれかを **1回だけ** 行ってください。

- **URL の末尾に `?new` を付けて開く**（最も簡単）
  例：`https://<ユーザー名>.github.io/<リポジトリ名>/tools/toritsu-kanji/?new`
- または、ブラウザのキャッシュ（サイトデータ）を消してから開く
  - iPhone（Safari）：設定 → Safari → 履歴とWebサイトデータを消去
  - Android（Chrome）：メニュー → 設定 → プライバシー → 閲覧履歴データの削除（キャッシュ）
- ホーム画面に追加している場合は、いったん削除して追加し直す

一度これで新しい版が読み込まれれば、以後は自動で最新になります。

## ローカルでの確認

`index.html` をブラウザで直接開くか、簡易サーバーで確認します。

```bash
python -m http.server 8080
# → http://localhost:8080/tools/toritsu-kanji/
```

## データの保存について

学習履歴・成績・追加問題・日別の学習量は、その端末のブラウザの
localStorage に保存されます（端末・ブラウザをまたいでの同期はされません）。
