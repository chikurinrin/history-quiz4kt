# 夏の進捗管理

中学3年生の、夏休みの学習プランと進捗管理ボード。
バックエンドなし。記録はブラウザの localStorage にのみ保存される（外部送信なし）。

**学校名はコードに持たない。** 見出しは既定で「希望校」と表示し、設定タブで入力した名前だけが
その端末の localStorage に入る。プランの中身は
**進学指導重点校（国数英が自校作成／理社が都立共通問題）** を前提に組んである。

**設計方針：入力負担を最小にする。** 毎日の記録はボタンのタップだけで完結し、
数字の入力は「学習時間」と「速読タイム」だけ（どちらも任意）。集計はすべて自動。

## 起動

```powershell
powershell -ExecutionPolicy Bypass -File serve.ps1
```

`http://localhost:8080/tools/summer-plan/index.html` を開く。

## 画面

| タブ | 内容 |
|---|---|
| **今日の記録** | 既定の画面。教科ごとにボタンをタップするだけ |
| ダッシュボード | 教科別の理解度、速読スピードの推移、日別・教科別の学習時間、直近7日の実施状況 |
| 分野の進捗 | **理解度（4段階・自己申告）** と **繰り返し回数** を分野ごとに入力・更新する |
| 夏の工程表 | 3つの期と重点、日別カレンダー |
| 合格ライン逆算 | 内申（換算内申65点）→ 調査書点300点 → 当日必要な学力検査点。最初に一度入れるだけ |
| 攻略ガイド | 希望校の入試構造、毎日のかたち、タイムテーブル、やらないことリスト |
| 設定 | 希望校名・期間・入試日・目標時間、JSONの書き出し／読み込み、全削除 |

## 「今日の記録」のチェック項目

- **英語**（毎日）：日中＝長文の復習（速読）／夜＝新しい長文1題／早稲田アカデミー 夏期講習／宿題
  - 任意で「語数」と「かかった時間」を入れると wpm を計算し、推移グラフに反映
- **国語**：漢字アプリ（毎日）／現代文（2日ごと・夜）／古文（2日ごと・夜）／夏期講習／宿題
  - 2日ごとの項目には前回からの日数が出て、`every` 日以上空くと赤バッジになる
- **数学・理科・社会**：分野 × 教材のマトリクス。やった分野の、やった教材をタップする
  - 教材＝問題集／過去問題／教科書確認／早稲田アカデミー 夏期講習／早稲田アカデミー 宿題
  - 分野＝数学20（数と式・方程式・関数・図形・データ）、理科12（中1〜中3の各4）、
    社会28（地理10・歴史10・公民8）

## 「分野の進捗」タブ

やった量ではなく**手ごたえ**で進捗を測るための画面。分野ごとに次を入力する。

- **理解度**（4段階・自分で更新）：`未` 未着手／`△` 苦手／`○` あと少し／`◎` できる
- **繰り返し回数**：問題集を − / ＋ で増減（`MATERIALS[].rep` が true のものだけ表示される）
- 参考表示として、その分野を「今日の記録」でチェックした日数が教材別に出る（自動集計）

## データ構造（localStorage キー `summer-plan-v1`）

※ 旧キー `nishi-summer-v1` に記録があれば、起動時に自動で引き継いで旧キーを消す（`migrateOldKey()`）。

```jsonc
{
  "settings": { "school": "", "start": "2026-07-21", "end": "2026-08-31",
                "exam": "2027-02-21", "goalHours": 10, "targetTotal": 760,
                "lastBackup": "2026-08-01T08:30:00.000Z" },
  "days": {
    "2026-08-01": {
      "h":  { "ma": 2.5 },                  // 教科別の学習時間（任意）
      "en": { "rev": true, "new": true },   // 英語の毎日チェック
      "jp": { "kanji": true },              // 国語のチェック
      "f":  { "sc-3-sel": true },           // 分野ID-教材キー
      "rd": { "w": 800, "m": 6 },           // 速読：語数 / 分（任意）
      "memo": ""
    }
  },
  "und":  { "ma-0": 3 },                  // 分野ID → 理解度 0〜3
  "reps": { "ma-0": { "sel": 2, "kako": 1 } },  // 分野ID → 教材ごとの周回数
  "naishin": { "five": [5,4,5,5,4], "four": [4,5,4,5], "esat": "A" }
}
```

分野IDは `教科キー-通し番号`（`fieldList()` が `FIELDS` から生成）。

## ファイル

- `data.js` — 分野マスタ・教材種別・理解度の段階・英語/国語の毎日メニュー・期の定義（内容の変更はここだけで済む）
- `script.js` — 状態管理、SVGチャート（外部ライブラリなし）、各画面の描画
- `style.css` — ライト／ダーク両対応。配色はCVD検証済みのカテゴリカル8色から使用

## 内容を変えるとき

- 塾の名前：`JUKU`（1箇所直せば全画面に反映される）
- 速読の目標スピード：`READ_SPEED = { base: 120, goal: 150 }`。ラベル・ヒント・グラフの基準線・
  ダッシュボードのスタッツがすべてこの値を見ている
- 毎日のメニュー：`EN_DAILY` / `JP_DAILY`。`every` は何日ごとにやるか（1=毎日、2=2日ごと、0=縛りなし）
- 教材の種別：`MATERIALS`（列が増減する。グリッドの列数はJSが自動で合わせる）。
  `rep: true` にすると「分野の進捗」タブで周回数を数えられるようになる
- 理解度の段階：`LEVELS`（増減させる場合は `style.css` の `.lv-btn.on.lN` / `.lv-sw.lN` も足す）
- 分野の追加：`FIELDS`。**IDが配列インデックス由来なので、途中に挿入すると過去の記録がずれる。追加は各教科の末尾に**
  （名前の変更は記録に影響しない）
- 分野名は**8文字以内**に保つこと。スマホ縦画面で1行に収めるため、それ以上は末尾が「…」になる
- 期の配分：`PHASES[].ratio`（合計1.0）。日付は設定タブの期間から自動計算される
