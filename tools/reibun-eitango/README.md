# 例文で覚える英単語

例文300文から抽出した重要語 1210 語を、**赤シート・フラッシュカード・4択テスト・自動再生**で覚えるツールです。
**向き（英→日／日→英）ごとに習熟を別々に記録**し、**間隔反復**で「今日復習すべき語」だけを出題できます。
バックエンド不要・すべてブラウザ内（localStorage）で完結します。PWA対応（ホーム画面に追加するとアプリとして起動・オフライン動作）。

## 主な機能

- **向き別の習熟管理**：同じ語でも「英→日（読んで分かる）」と「日→英（言える・書ける）」を別々に記録
- **4段階の自己採点**：◯正解／△あいまい／✕苦手／−カウントしない
- **今日の復習（間隔反復）**：正解するほど復習間隔が延びる（1→3→7→14→30→60日）。期限が来た語だけを出題
- **セクション別進捗**：1210語を100語ずつ13セクションに分割。横棒グラフ＋チェックボックスで範囲指定
- **赤シート単語リスト**：意味／英語のどちらかを隠して確認。タップでその語だけ表示。検索・区分での絞り込み・区分の手動変更
- **4択テスト**：10／20／50／全問。結果画面に間違い一覧と「間違いだけ復習」
- **自動再生（かけ流し）**：表→答えを一定間隔で自動送り。読み上げは「単語だけ／単語＋意味＋例文／音声なし」を選択、繰り返し再生も可
- **成績分析**：全体・セクション別に、向きごとのマスター率と正答率
- **学習履歴**：日ごとの解答数を約6か月分の棒グラフで表示。連続学習日数・学習日数・のべ解答数
- **ダークモード**：OSの設定に追従。フッターのボタンで切替
- **エクスポート／インポート**：JSONで成績・履歴をバックアップ
- **ごほうびゲーム**：4択テストで5問正解するごとにライフ1機。グラディウス風の横スクロールシューティングが遊べる

## 覚え方の目安

1. **セクションを1つ選ぶ** → 「単語リスト（赤シート）」でひと通り眺める
2. **「学習をはじめる（カード）」** で自己採点しながら1周する
3. 翌日以降はホームの **「🔁 今日の復習を始める」** を押すだけ（期限が来た語だけ出ます）
4. 仕上げに **4択テスト**、移動中は **自動再生** でかけ流し

「◯正解」が2回続くとマスター扱いになり、ダッシュボードの進捗バーが伸びます。

## ごほうびゲームについて

**4択テストで5問正解するごとに、ゲームのライフが1機もらえます。**
問題数（10問／20問／50問／全部）に関係なく、同じ計算です。

| 正解数 | もらえるライフ |
|---|---|
| 0〜4問 | なし |
| 5問 | 1機 |
| 10問 | 2機 |
| 25問 | 5機 |
| 50問 | 10機 |

1回のテストでたまるのは「ライフ◯機ぶんのプレイ権が1つ」です。あと少しで1機増えるときは、
結果画面に「あと 2問正解でもう1機でした」と出ます。

たまったプレイ権はホームの「🎮 ごほうびゲームであそぶ」から使えます（START を押した時点で1つ消費します）。
繰り越せるので、ためておいてまとめて遊べます。複数あるときは、**ライフの多いものから使います**
（ボタンに「あと 3 回・次は ♥5」のように出ます）。

※「全部」で大量に解いたときの歯止めとして、1回でもらえるライフは **20機** を上限にしています。

グラディウス風の横スクロールシューティングですが、**遊びながら英単語に触れられる**ようにしてあります。

### 英語の仕掛け

- **単語エネミー**：英語をかかげた敵が飛んでくる。**1発当てると日本語に変わり**、もう1発でたおせる
  （意味が分からないときは、1発当てて確かめてから倒せる＝ヒントになる）
- 倒すと「**英語 ＝ 意味**」が浮かび上がる
- **おだい**：ときどき画面上に日本語の意味が出て、それに合う単語の敵が3機やってくる。
  正解の敵を倒すと **+2000点・カプセル1個・「せいかい！」**。ちがう敵を倒すとその語の意味が出るだけ
- 出てくる単語は、**いま苦手・あいまいな語と、今日の復習の語を優先**して選ばれます
  （次に選んでいるセクションの語、それでも足りなければ全語から補います）
- 結果画面に「**たおした単語**」「**おだい正解**」の数が出ます

ゲームの結果は学習記録（正解・苦手の区分や復習日）には反映しません。ゲームで当てずっぽうに当たった分が
学習の記録を汚さないようにするためです。ゲームはあくまで「目に触れる回数を増やす」役割です。

### 遊び方・ルール

- 操作：矢印キー / WASD で移動、スペース（または J）で連射、Z（または K）でパワーアップ発動。スマホは画面下のボタン
- カプセル **C** を取るとパワーメーターが1つ進み、好きなところで発動できます
  （SPEED → MISSILE → DOUBLE → LASER → OPTION → SHIELD）
- 敵の編隊（5機）を全部倒すとカプセルが出ます
- ライフはプレイ権ごと（テストの正解数で決まる）。ステージ制で、一定時間でボスが出て、倒すと次のステージへ（少しずつ強くなります）
- 上下の地形は見た目だけで、当たっても大丈夫です
- やられてもパワーアップは消えません（遊びやすさを優先しています）

もらえるライフの計算を変えたいときは `script.js` の `REWARD_PER_LIFE`（何問正解でライフ1機か）と `REWARD_MAX_LIVES`（上限）を、
プレイ権から指定が無いときの既定ライフは `game.js` の `START_LIVES` です。

## ローカルでの確認

リポジトリ直下の `serve.ps1` を使います（Python / Node 不要）。

```powershell
powershell -ExecutionPolicy Bypass -File serve.ps1
```

→ `http://localhost:8080/tools/reibun-eitango/`

Service Worker と PWA はローカルサーバー経由（`http://localhost`）でないと動きません。

## データの保存について

成績・区分・日別の学習量・設定は、その端末のブラウザの localStorage に保存されます
（端末・ブラウザをまたいでの同期はされません）。移行したいときはエクスポート／インポートを使ってください。

保存に使うキーは次のとおりです。

| キー | 内容 |
|---|---|
| `reibun-eitango.history` | 語×向きごとの成績・区分・次回復習日 |
| `reibun-eitango.daily` | 日別の学習量 |
| `reibun-eitango.settings` | 出題設定（向き・範囲・問題数など） |
| `reibun-eitango.theme` | ライト／ダークの選択 |
| `reibun-eitango.reward` | ごほうびゲームのプレイ権（1回ぶんのライフ数の配列）・達成回数・ハイスコア |

旧バージョン（覚えた／あいまいの2段階）の記録 `reibun-eitango:v1` は、初回起動時に自動で新形式へ取り込みます。

## データを増やす・直す

`data.js` の `SENTENCES` に `{ id, en, ja, words: [[英語, 意味], ...] }` を足すだけで、
番号の振り直し・セクション分割・全モードへの反映まで自動で行われます。
同じ語が複数の例文に出てくる場合は最初の例文が代表になり、残りは「ほかの例文」として答え合わせ画面に出ます。
